# Vigenere Cipher (WinForms)
This is my implementation of the Vigenere Cipher, which I developed during college.

## Features
* **Encryption & Decryption:** Full support for the Vigenere cipher algorithm.
* **Alphabet Selection:** Toggle between different alphabets (including Cyrillic).
* **User-Friendly Interface:** Clean and classic WinForms UI split into distinct areas for encoding and decoding.

# RU 
# Шифр Виженера (WinForms)

Это моя реализация шифра Виженера, которую я разработал во время учёбы в колледже.

## Возможности программы
* **Шифрование и дешифрование:** Полная поддержка алгоритма шифра Виженера.
* **Выбор алфавита:** Возможность переключения между различными алфавитами (включая латинницу).
* **Удобный интерфейс:** Чистый и классический UI на WinForms, разделенный на независимые зоны для кодирования и декодирования текста.
